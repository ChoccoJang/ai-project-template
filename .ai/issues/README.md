# 오픈 이슈

미해결이거나 의도적으로 미룬 이슈. 해결되면 상태를 갱신하거나 항목을 제거하고,
필요하면 관련 ADR을 링크한다. 형식은 [`0000-이슈-템플릿.md`](./0000-이슈-템플릿.md) 참고.

상태 어휘는 [`../README.md`](../README.md)의 "이슈 관리" 절이 단일 출처다(여기에 중복하지 않는다).

아직 등록된 이슈가 없다. 첫 이슈를 `0001-슬러그.md`로 만들고 아래 표에 한 줄 추가한다.

| 제목 | 상태 |
|---|---|
| (없음) | — |

기입 예시(실제 파일이 생기면 이 형식으로 바꾼다):

```markdown
| [수집 주기 설정이 재시작 시 초기화됨](./0001-수집-주기-초기화.md) | Open |
```
