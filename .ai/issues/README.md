필요하면 관련 ADR을 링크한다. 형식은 [`0000-template.md`](./0000-template.md) 참고.

상태 어휘는 [`../README.md`](../README.md)의 "이슈 관리" 절이 단일 출처다(여기에 중복하지 않는다).

(슬러그는 영문 소문자·숫자·하이픈만 — ADR 0003).

| # | Phase | 제목 | 상태 |
|---|---|---|---|
| [0001](./0001-pr-creation-permission.md) | 해당 없음 | 에이전트가 PR을 생성할 수 없다 (pulls API 404) | Deferred(환경 제약) |
