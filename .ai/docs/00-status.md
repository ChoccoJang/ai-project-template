# 00. Project Status

## 목적

프로젝트의 "현재 상태"(어느 단계이고 무엇이 구현되었는지)를 한 곳에서 관리한다. 상태 정보가
`README.md` 배지, `AGENTS.md`의 로드맵 등에 흩어져 있으면 갱신이 누락되기 쉽다 —
이 문서를 단일 출처(single source of truth)로 삼는다.

다른 문서는 상태를 자체 서술하지 않고 이 문서를 인용한다.
