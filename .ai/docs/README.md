# 개발 문서 (.ai/docs)

컴포넌트 상세 설계와 구현 현황 등 **개발용 문서**다. 저장소에서만 본다.

| 문서 | 내용 |
|---|---|
| [00-status](./00-status.md) | 컴포넌트별 구현 현황 (상태의 단일 출처) |
| [07-api-design](./07-api-design.md) | REST API 계약 (단일 출처) |

컴포넌트 설계 문서는 아직 없다. 새로 만들면 위 표에 한 줄 추가한다.

### 번호 배정 관례

- **고정 번호 두 개.** `00` = 구현 현황, `07` = REST API 계약. 다른 문서에 쓰지 않는다.
- **그 외 번호는 미리 예약하지 않는다.** 문서를 실제로 만들 때 비어 있는 가장 작은 번호를
  가져다 쓴다(`01`, `02`, `03`, `04` …). 표에 없는 번호는 "예약됨"이 아니라 "비어 있음"이다.
- 파일명은 `NN-{{컴포넌트}}-design.md` 형식으로 짓는다(예: `01-server-design.md`).
- 번호는 문서를 지우거나 통폐합해도 **재사용하지 않는다** — 다른 문서와 커밋이 번호로 참조하기
  때문이다. 없어진 번호는 이 표 아래에 "N은 M으로 통합됨"으로 남긴다.

새 문서는 [`0N-컴포넌트-설계-템플릿.md`](./0N-컴포넌트-설계-템플릿.md)를 복사해 만들고 이 표에
한 줄 추가한다. 결정 기록은 [`../adr/`](../adr/), 오픈 이슈는 [`../issues/`](../issues/) 참고.
