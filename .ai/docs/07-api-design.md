## 설계

### 공통 규칙

- Base path: `/api/v1`
- 시간 필드는 epoch milliseconds
- 인증: `Authorization: Bearer <token>` <!-- 인증이 없으면 "해당 없음" -->
- 에러 응답 형식:

  ```json
  { "status": 400, "message": "설명", "timestamp": 1710000000000 }
  ```

- 상태 코드 관례: `400` 잘못된 요청 · `401` 미인증 · `403` 권한 없음 · `404` 없음 ·
  `409` 충돌(중복/참조 중)

### 엔드포인트 목록

| 메서드 | 경로 | 인증 | 설명 |
|---|---|---|---|
| `POST` | `/api/v1/{{리소스}}` | 관리자 | {{설명}} |
| `GET` | `/api/v1/{{리소스}}` | 인증 | {{설명}} |
| `GET` | `/api/v1/{{리소스}}/{id}` | 인증 | {{설명}} |
| `PUT` | `/api/v1/{{리소스}}/{id}` | 관리자 | {{설명}} |
| `DELETE` | `/api/v1/{{리소스}}/{id}` | 관리자 | {{설명}} |

### {{리소스}} 상세

#### `GET /api/v1/{{리소스}}`

쿼리 파라미터:

| 이름 | 타입 | 필수 | 기본값 | 설명 |
|---|---|---|---|---|
| `from` | number | N | 1시간 전 | 조회 시작 시각(epoch ms) |
| `size` | number | N | `20` | 페이지 크기 |

## 예시

### 요청

```http
GET /api/v1/{{리소스}}?size=20 HTTP/1.1
Authorization: Bearer eyJhbGciOi...
```

### 응답

```json
{
  "content": [
    { "id": 1, "name": "example", "createdAt": 1710000000000 }
  ],
  "page": 0,
  "size": 20,
  "totalElements": 1
}
```
