# 07. API 설계 (인터페이스 계약)

## 목적

이 저장소의 **인터페이스 계약 단일 출처**다. `AGENTS.md` 8절이 여기를 가리키고, 클라이언트
(프론트엔드 등)는 이 문서의 계약만 소비한다. 계약을 바꿀 때는 **이 문서와 코드를 함께** 고친다
(문서 없이 계약 변경 금지 — `AGENTS.md` 12절).

> **형식 전제.** 아래 구조는 HTTP/REST를 전제로 쓰여 있다. GraphQL·gRPC·메시지 큐·CLI 등
> 다른 방식이면 "공통 규칙"과 "엔드포인트 목록"을 그 방식의 단위(스키마·서비스·토픽·명령)로
> 바꿔 쓴다. 외부에 노출하는 인터페이스가 아예 없으면 이 문서를 지우고 `AGENTS.md` 8절과
> `.ai/docs/README.md` 인덱스를 "해당 없음"으로 표기한다.

## 설계

### 공통 규칙

값은 프로젝트에서 정한다. "흔한 선택"은 참고용이며 그대로 쓸 의무가 없다 —
정하고 나면 자리표시자를 지우고 확정값만 남긴다.

| 항목 | 이 프로젝트의 값 | 흔한 선택 |
|---|---|---|
| 프로토콜 | `{{프로토콜}}` | HTTP/REST · gRPC · GraphQL · 메시지 큐 |
| 기본 경로 | `{{API-기본경로}}` | `/api/v1` |
| 버전 정책 | `{{버전-정책}}` | 경로 버전(`/v1`) · 헤더 버전 · 버전 없음 |
| 인증 | `{{인증-방식}}` | `Authorization: Bearer <token>` · 세션 쿠키 · 해당 없음 |
| 시간 표현 | `{{시간-표현}}` | epoch milliseconds · ISO-8601 문자열 |
| 식별자 형식 | `{{식별자-형식}}` | 정수 시퀀스 · UUID · 외부 시스템 키 |
| 페이지네이션 | `{{페이지네이션-방식}}` | offset/size · cursor · 해당 없음 |

시간 표현과 식별자 형식은 `AGENTS.md` 6절(Data Model)의 값과 **반드시 같아야 한다.**

### 에러 응답

에러 응답 형식은 하나로 고정한다. 아래는 형태 예시이므로, 프로젝트 형식을 확정해 이 블록을
교체한다.

```json
{ "status": 400, "message": "설명", "timestamp": 1710000000000 }
```

에러 분류 체계(`{{에러-분류-체계}}`)도 여기에 고정한다. HTTP를 쓴다면 흔한 관례는
`400` 잘못된 요청 · `401` 미인증 · `403` 권한 없음 · `404` 없음 · `409` 충돌(중복/참조 중)이다.
