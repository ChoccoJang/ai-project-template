# 작업 결과 문서

작업이 끝날 때마다 결과를 한 파일로 남긴다. 형식은 이 폴더의
[`0000-작업결과-템플릿.md`](./0000-작업결과-템플릿.md)를 따르고,
본문(작업내용/최종정리내용)은 [`pull_request_template.md`](../../.github/pull_request_template.md)의
각 섹션을 채워서 작성한다.

- 파일명: `yyyymmdd-작업명.md` (예: `20260731-로그-수집-추가.md`)
- 작업 브랜치는 PR 병합 후 삭제한다. 환경/권한 문제로 삭제하지 못하면 그 파일의
  **참고사항** 영역에 적는다(별도 안내 없이).
