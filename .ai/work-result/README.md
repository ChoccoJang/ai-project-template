# 작업 결과 문서

작업이 끝날 때마다 결과를 한 파일로 남긴다. 형식은 이 폴더의
[`0000-template.md`](./0000-template.md)를 따른다.

- 파일명: `yyyymmdd-slug.md` (예: `20260731-log-collector.md`). 슬러그는 영문 소문자·숫자·
  하이픈만 쓴다(ADR 0003).
- **PR 본문과 중복해서 쓰지 않는다.** 목적·배경·검증·체크리스트는 PR이 담고, 이 문서는
  요청사항·변경 요약·최종 정리·참고·제안을 담는다(ADR 0004).

새 문서를 추가하면 아래 표에 한 줄 등록한다.

| 작업일시 | Phase | 제목 | 작업자 |
|---|---|---|---|
| 2026-08-19 | 해당 없음 | [문서 구조 정비 — 파일명·기록 역할·Phase 필드·status 통합·규약 검사](./20260819-doc-structure-overhaul.md) | Claude Code |

기입 예시(실제 파일이 생기면 이 형식으로 바꾼다):

```markdown
| 2026-07-31 | A-2 | [로그 수집 추가](./20260731-log-collector.md) | Claude Code |
```
