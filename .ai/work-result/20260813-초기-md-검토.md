## 최종정리내용

검토에서 나온 15건을 모두 반영했다. 깨진 링크 6건 제거, `work-result` 누락 보강, 문서 형식
규칙의 적용 범위 확정, 빌드/실행 절 신설, 자리표시자 체계 정리, 대상 에이전트를 Claude Code와
Codex로 확정했다. 링크 깨짐이 재발하지 않도록 CI 검사를 추가했다.

이어서 2차로, 템플릿에 박혀 있던 특정 기술 전제(REST 경로·Bearer 인증·epoch milliseconds·
Spring Page 응답 형태·Java 전용 코딩 규칙)를 모두 자리표시자로 바꿨다.

3차로 구조 자체를 범용화했다. `.ai/`는 상태(`status.md`)·ADR·이슈·작업결과 네 가지로 줄이고
`docs/` 계층과 API 설계 문서를 삭제했으며, AGENTS.md를 13절로 개편해 MVP 전제와 인터페이스
전제를 제거했다. 인터페이스 계약은 "있다면" 절로 남아, 필요한 프로젝트만 문서를 만든다.

4차로 "할 일"의 단일 출처를 정리했다. AGENTS.md 12절 Current Priority를 삭제하고(13절
Definition of Done이 12절로 승격, 최종 12절 구성), 우선순위를 `.ai/status.md`의
"우선순위 (다음에 할 일)" 절로 옮겨 기존 "남은 작업" 절과 통합했다. 우선순위는 규칙이 아니라
자주 바뀌는 상태이므로 상태 SSOT에 두는 것이 맞고, 이제 할 일은 status.md 한 곳에서 본다
(문제·보류 건은 `.ai/issues/`).
