# Phase 명명 규칙 신설 (AGENTS 14절)

- **작업일시** : 2026-08-19
- **작업자** : Claude Code (claude/20260819-phase-명명-규칙)

## 작업요청사항

Phase 관련 규칙이 없어 지정이 필요하다.

- Phase는 대문자 영어 한 글자(`A`, `B`, …)로 표기한다.
- 각 Phase의 소분류는 `A-1` 형식으로 표기한다.
- **소분류까지만 분리한다.**

## 작업내용

### 목적

계획을 단계로 나눠 진행하는데 그 표기 규칙이 없어, 문서마다 `1단계`·`Phase 1`·`Step A`가
섞이고 하위 항목이 얼마나 깊어져도 되는지 기준이 없었다. 표기와 **분리 깊이 상한**을 규칙으로
고정해 저장소 전체에서 같은 토큰(`A-2`)으로 계획을 가리킬 수 있게 했다.

  다음 번호로 이어 붙인다는 `README.md` 4항을 따라 13절 뒤에 추가했다.
