# Phase 명명 규칙 신설(AGENTS 14절)과 브랜치 규칙 정비

- **작업일시** : 2026-08-19
- **작업자** : Claude Code (claude/phase-naming-rules-icc7yp)

## 작업요청사항

1. Phase 관련 규칙이 없어 지정이 필요하다.
   - Phase는 대문자 영어 한 글자(`A`, `B`, …)로 표기한다.
   - 각 Phase의 소분류는 `A-1` 형식으로 표기한다.
   - **소분류까지만 분리한다.**
2. 한글 브랜치명이 자꾸 걸리고, 규칙에 맞춘 재명명 때문에 작업 하나에 브랜치가 둘 생긴다 —
   규칙을 바꾼다.
   - 브랜치 삭제는 **로컬만 AI 에이전트가** 하고, **원격은 소유자가** 한다.
   - 작업 결과 문서에 브랜치 삭제 문구를 넣는 규칙은 뺀다.

## 작업내용

### 목적

**Phase.** 계획을 단계로 나눠 진행하는데 표기 규칙이 없어 문서마다 `1단계`·`Phase 1`·`Step A`가
섞이고, 하위 항목이 얼마나 깊어져도 되는지 기준이 없었다. 표기와 **분리 깊이 상한**을 고정해
저장소 전체에서 같은 토큰(`A-2`)으로 계획을 가리킬 수 있게 했다.

**브랜치.** 9절이 한글 작업명을 요구하고 `CLAUDE.md`가 세션 브랜치를 규칙에 맞게 재명명하도록
정하고 있어, 작업 하나에 브랜치가 둘 생기고 원격에 빈 브랜치가 남았다. 한글 브랜치명 자체도
터미널·git 출력에서 인코딩 형태로 보여 다루기 번거로웠다. 브랜치 삭제 주체도 불분명해,
에이전트가 원격 삭제에 실패하고 그 사실을 매번 작업 결과에 적는 절차가 반복됐다.

### 변경 내용

**Phase 규칙 (AGENTS 14절 신설)**

- 새 규칙은 절 번호를 바꾸지 않고 다음 번호로 이어 붙인다는 `README.md` 4항에 따라 13절 뒤에
  `14. Phase Rules`를 추가했다.
  - 표기: Phase = 대문자 한 글자(`Phase A`), 소분류 = `대문자-숫자`(`A-1`), 번호는 Phase마다
    `1`부터.
  - **분리 깊이: 소분류까지만.** `A-1-1`·`A-1-a` 금지. 더 쪼개야 하면 다음 소분류로 나누거나
    본문 체크리스트로 푼다.
  - 부여한 문자·번호는 재사용/재번호하지 않는다(외부 참조 보호).
  - 쓰는 곳: `.ai/status.md`, ADR·이슈·작업 결과 본문, (선택) 브랜치·PR 제목.
- `.ai/status.md`: `현재 단계` → `현재 Phase`, **`Phase 구성` 표**(Phase/소분류/목표/상태) 추가,
  우선순위 항목 앞에 소분류(`A-2`) 표기.
- `.ai/README.md`: status 항목에서 Phase 표기 규칙이 14절임을 가리킴.
- `.ai/adr/0001-phase-명명-규칙.md` 신규 + 인덱스 등록.

**브랜치 규칙 (AGENTS 9절 개정)**

- 브랜치명 형식을 `claude/yyyymmdd-work-name`으로 **영문 소문자화**했다(한글·공백·대문자 금지,
  예: `claude/20260716-search-feature`).
- **재명명 금지 조항 추가:** 도구·세션이 만든 `claude/*`·`codex/*` 브랜치는 날짜가 없거나 임의
  접미사가 붙어 있어도 그대로 쓴다. 형식은 에이전트가 브랜치를 직접 만들 때만 적용한다.
- **브랜치 정리 규칙 교체:** 로컬 브랜치는 에이전트가 지우고, **원격 브랜치는 소유자가**
  지운다(에이전트는 `git push origin --delete`를 실행하지 않는다). 브랜치 삭제 여부를 작업 결과
  문서에 적는 규칙은 삭제했다.
- `CLAUDE.md`: "작업 시작 시 브랜치 정합"(재명명) 규칙을 삭제하고, 세션 브랜치를 그대로 쓰고
  원격 브랜치는 삭제하지 않는다는 항목으로 교체했다.
- `.ai/work-result/README.md`·`0000-작업결과-템플릿.md`: 브랜치 삭제 기록 안내 문구 삭제.
- `AGENTS.md` 14절의 브랜치 예시도 영문 표기(`claude/20260819-a-1-search-feature`)로 맞췄다.
- `.ai/adr/0002-브랜치-명명과-삭제-책임.md` 신규 + 인덱스 등록.
