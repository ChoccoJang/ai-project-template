# PR 리뷰 통과 신호(👍) 규칙 추가

- **작업일시** : 2026-08-19
- **작업자** : Claude Code (main 직접 커밋)

## 작업요청사항

PR 본문에 👍 1개가 달리면 Codex가 "제안이 없으면 👍로 반응한다"고 안내하는 방식이라,
지적 없이 리뷰를 통과한 신호로 본다는 내용을 규칙에 추가한다.

## 작업내용

### 목적

9절 이모지 규칙이 🚀(머지 승인)만 정의하고 있었고, 👍는 "승인으로 보지 않는다"고만 적혀
있어 **리뷰 통과를 뜻하는 신호**라는 사실이 규칙에 없었다. Codex가 지적 없을 때 👍로 반응하는
방식으로 동작하므로, 에이전트가 그 신호를 읽고 "리뷰는 끝났고 지적은 없다"를 판단할 수 있어야
한다.

### 변경 내용

- `AGENTS.md` 9절에 **`#### 👍 = 리뷰 지적 없음 (리뷰 통과 신호)`** 절 추가.
  - Codex는 "제안이 없으면 👍로 반응한다"고 안내하는 방식이므로, **PR 본문의 👍 1개**를
    지적 없이 통과한 신호로 본다(`reactions.+1` 카운트로 확인).
  - **👍는 머지 승인이 아니다** — 머지는 🚀 + CI green이 여전히 필요하다.
  - 👍가 없다고 리뷰 실패로 보지 않는다(리뷰 전일 수 있음). 리뷰 코멘트가 있으면 코멘트가
    우선이며 반영 후 스레드를 resolve한다.
  - 🚀와 같은 한계(누가 눌렀는지 못 봄) — 👍가 2개 이상이면 코멘트로 실제 결과를 확인한다.
- `AGENTS.md` 9절 기존 이모지 승인 항목: "다른 이모지(👍 등)는 승인으로 보지 않는다"를
  "👍는 승인이 아니라 리뷰 통과 신호"로 다듬고, 자동 추적 항목의 확인 대상에 👍를 포함.
- `CLAUDE.md` PR 추적 2번(예약이 깨어났을 때 확인 순서)에 👍(리뷰 통과) → 🚀(머지 승인) 순서 반영.
